# Arsip dokumen era GEMASTIK

Dokumen di folder ini ditulis pada era GEMASTIK XIX 2026 (Juli–Agustus 2026) dan **bukan acuan fase Tugas Akhir**. Isinya dipertahankan sebagai catatan proses. Kode yang dirujuk dokumen-dokumen ini dapat dilihat pada tag [`gemastik-xix-2026`](https://github.com/MoodInBME/Software-Architecture/tree/gemastik-xix-2026).

| Berkas                                | Isi                                                                                   |
| ------------------------------------- | ------------------------------------------------------------------------------------- |
| `CODE_REVIEW_data_layer.md`           | Telaah lapisan data dan kartu dataset UBFC-rPPG                                       |
| `CODE_REVIEW_root_files.md`           | Telaah enam berkas root awal                                                          |
| `CODE_REVIEW_stc_rppg.md`             | Telaah komponen STC-rPPG dan usulan tambalan                                          |
| `CONSOLIDATION.md`                    | Paket perbaikan struktur repo                                                         |
| `MIGRATION.md`                        | Migrasi skrip root ke struktur folder                                                 |
| `PATCH_NOTES.md`                      | Catatan tambalan rev-b (6 Agustus 2026), termasuk bagian yang tidak pernah diterapkan |
| `ST-GCN-PLAN.md`, `ST-GCN-PLAN-v2.md` | Rencana jalur wajah dan fusi valensi-_arousal_                                        |
| `FIGMA_RENAME.md`                     | Penamaan _frame_ Figma untuk UI QML (urusan antarmuka)                                |

Kode tambalan `S1`–`S7` di dokumen ini berbeda dari kode uji pendahuluan di proposal TA.
